# 대화 이어하기

이 폴더에는 `dev-studio-broadcast`를 만들며 나눈 중요한 대화와 다음 작업을 저장합니다.

## 이어서 작업하는 방법

1. 가장 최근 날짜의 `.md` 파일을 엽니다.
2. `현재 상태`와 `다음 작업`을 확인합니다.
3. 이 파일을 AI 대화에 넣고 이렇게 말합니다.

```text
이 대화 기록을 읽고 dev-studio-broadcast 작업을 이어서 해 줘.
다음 작업부터 진행해.
```

## 파일 이름

`YYYY-MM-DD-짧은-제목.md`

새로운 대화를 끝낼 때마다 현재 상태와 다음 작업을 새 파일로 남깁니다.
