# dev-studio-broadcast 작업 이어하기

## 목표

게임·교안·개발 과정을 방송처럼 기록하고 보여 주는 개인 개발 방송국을 만든다.

## 현재 상태

- GitHub 저장소: https://github.com/jes79/dev-studio-broadcast
- 첫 화면 제작 완료
- 현재 게임: 심상 배달
- 진행률 샘플: 32%
- 최근 개발 기록·작품 채널 표시
- 게임별 채널 화면 표시
- 게임별 개발 대화 기록을 브라우저에 저장하고 새로고침 후 복원
- GitHub에 커밋·푸시 완료

## 이번에 만든 것

- `index.html`: 방송국 메인 화면과 개발 대화 영역
- `src/styles.css`: 방송국·대화 섹션 디자인
- `src/app.js`: 샘플 데이터와 대화 입력 동작
- `docs/vision.md`: 프로젝트 방향
- `docs/screen-design.md`: 첫 화면 설계
- `data/broadcasts.json`: 방송 샘플 데이터
