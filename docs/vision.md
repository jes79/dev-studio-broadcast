# 프로젝트 방향

## 한 줄

만드는 과정을 방송처럼 기록하고, 완성한 작업물을 전시하는 개인 개발 방송국.

## 첫 버전의 기준

사용자가 화면을 열었을 때 10초 안에 다음을 알 수 있어야 한다.

- 지금 무엇을 만들고 있는가
- 얼마나 진행했는가
- 최근 무엇을 바꿨는가
- 다음에 무엇을 할 것인가
- 작품을 어디에서 볼 수 있는가

## 이번 버전에서 하지 않는 것

- 실제 유튜브 자동 업로드
- 실시간 방송 송출
- 로그인·다중 사용자
- 복잡한 관리자 화면

## 다음 확장

게임 하나를 선택하면 그 게임의 개발 기록, 영상, 스크린샷, GitHub, 공개 페이지를 한 채널 안에서 보여 준다.
