# dev-studio-broadcast

동해님의 게임·교안·작업 과정을 방송처럼 기록하고 보여 주는 개인 개발 방송국입니다.

## 첫 버전

- 게임별 개발 대화 기록과 브라우저 저장
- 현재 작업 게임과 진행률
- 최근 개발 기록
- 작품 채널과 `#/showroom` 공개 작품 전시관
- GitHub 연결 및 실제 영상 주소 연결 자리

## 오늘의 개발 방송 사용법

1. 대시보드의 **오늘의 방송 만들기**에서 주제와 오늘 끝낼 목표를 입력하고 `방송 시작`을 누릅니다.
2. 온에어 화면에서 `방송 진행 시작`을 누르고 작업을 진행합니다. 타이머와 세션 내용은 새로고침해도 유지됩니다.
3. `방송 마감`을 눌러 결과·다음 작업·상태를 입력하고 `기록 저장`을 누르면 대시보드 최근 방송에 남습니다.

- 세션과 기록은 브라우저 `localStorage`에만 저장됩니다.
- 이 도구는 실제 유튜브 업로드나 실시간 송출을 하지 않습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 외부 패키지 없이 HTML·CSS·JavaScript로 시작합니다.

## 섹션

- `src/` — 화면과 동작
- `data/` — 나중에 분리할 게임·방송 데이터
- `docs/` — 기획·화면 설계·개발 기록
- `assets/` — 로고·썸네일·방송 이미지
