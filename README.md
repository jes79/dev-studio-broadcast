# dev-studio-broadcast

동해님의 게임·교안·작업 과정을 방송처럼 기록하고 보여 주는 개인 개발 방송국입니다.

## 첫 버전

- 게임별 개발 대화 기록과 브라우저 저장
- 현재 작업 게임과 진행률
- 최근 개발 기록
- 작품 채널과 `#/showroom` 공개 작품 전시관
- GitHub 연결 및 실제 영상 주소 연결 자리

## 현재 완료

- `#/dashboard`, `#/channel/simsang-delivery`, `#/showroom`, `#/on-air` 해시 라우트
- 녹화 준비용 타이머(경과 시간·일시정지·초기화)와 현재 준비 상태 표시
- 타이머는 이 브라우저의 `localStorage`에만 저장되며 실제 녹화·송출을 하지 않음
- 개발 중 작품 카드와 상세 상태, 실제 영상 주소 없음 안내
- GitHub 최근 커밋과 게임별 대화 저장 유지

## 다음 작업

- 실제 영상 주소 연결
- 게임 채널 추가
- 완성된 공개 작품 추가

## 실행

`index.html`을 브라우저로 열면 됩니다. 외부 패키지 없이 HTML·CSS·JavaScript로 시작합니다.

## 섹션

- `src/` — 화면과 동작
- `data/` — 나중에 분리할 게임·방송 데이터
- `docs/` — 기획·화면 설계·개발 기록
- `assets/` — 로고·썸네일·방송 이미지

## 장기 로드맵

1. 메인 대시보드
2. 게임별 방송 채널
3. 개발 기록 자동 연결
4. 쇼츠·블로그 자료 만들기
5. 공개 작품 전시관
6. 녹화용 방송 화면
